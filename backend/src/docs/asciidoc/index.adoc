== Catálogo de jugadores

Ambos endpoints requieren un JWT Bearer válido. La sincronización está disponible
para cualquier usuario autenticado, sin rol adicional. No se ejecuta automáticamente.

=== Consulta paginada

`GET /api/players` consulta exclusivamente la base local. `page` comienza en cero;
`size` admite valores de 1 a 100. Los valores predeterminados son 0 y 20.

=== Sincronización manual

`POST /api/players/sync` no recibe body. Primero obtiene Premier League (`PL`),
Bundesliga (`BL1`), La Liga (`PD`), Serie A (`SA`) y Ligue 1 (`FL1`), sin exigir un orden,
y después aplica la foto completa dentro de una transacción. Si falla cualquiera
de las cinco ligas, el catálogo permanece sin cambios. La configuración debe ser
el conjunto `PL,BL1,PD,SA,FL1` en cualquier orden; una lista incompleta, con duplicados o ligas adicionales impide el arranque.
Los jugadores ausentes se conservan como inactivos.
