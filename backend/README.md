# Football Market

Plataforma de mercado de jugadores de fútbol que permite consultar jugadores,
calcular y consultar sus cotizaciones, operar con tokens y gestionar el
portfolio de los usuarios.

## Stack

### Backend
- Java 21
- Spring Boot 3.x

### Frontend
- React
- Vite

### Base de datos
- PostgreSQL

### Herramientas
- GitHub Actions
- SonarCloud
- OpenAPI / Swagger
- JWT

## Estructura del proyecto

La aplicación estará compuesta por:

- Backend: API REST desarrollada con Spring Boot.
- Frontend: aplicación web desarrollada con React y Vite.
- Base de datos: PostgreSQL.

## Estado del proyecto

🚧 En desarrollo.

El proyecto se desarrolla siguiendo la metodología
**Spec-Driven Development (SDD)**.
