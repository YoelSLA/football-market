Necesitamos implementar una funcionalidad de registro y autenticación de usuarios.

Un usuario debe poder registrarse proporcionando un email y una contraseña. Para esta funcionalidad, se considera válido un email que no sea vacío y que contenga "@" y ".com". La contraseña debe ser no vacía.

El email debe ser único dentro del sistema. Si el email ya se encuentra registrado, el sistema debe rechazar el registro.

Una vez registrado, el usuario debe poder iniciar sesión utilizando el mismo email y contraseña con los que se registró. El sistema debe rechazar el inicio de sesión cuando el email no corresponda a un usuario registrado o cuando la contraseña no coincida con la correspondiente al usuario.

Los datos y credenciales utilizados para el registro y autenticación de usuarios deben protegerse durante su almacenamiento y procesamiento. Las contraseñas no deben almacenarse ni exponerse en texto plano, ni deben incluirse en respuestas, mensajes de error o registros del sistema.

El alcance de esta funcionalidad se limita al registro y al inicio de sesión. No incluye recuperación de contraseña, verificación de email, bloqueo de cuentas ni límites de intentos de autenticación.
