# Trabajo Práctico

Esta carpeta contiene la documentación oficial y los requisitos del Trabajo Práctico proporcionados por la materia.

## Archivos

### `enunciado.md`

Contiene el Documento de Visión oficial en Markdown y define el alcance general del Trabajo Práctico.

### `entregas.md`

Contiene las fechas y los requisitos específicos de los tres sprints, organizados en Core, Modelo y Funcionalidad. Agrega requisitos y condiciones específicas por entrega.

## Uso de esta documentación

Ambos archivos son fuentes de requisitos del proyecto. Un requisito no debe descartarse porque aparezca solo en uno de los dos documentos.

Los agentes de desarrollo deben consultar esta carpeta al:

- crear specs;
- aclarar requisitos;
- crear planes;
- generar tareas;
- implementar funcionalidades;
- analizar cumplimiento;
- revisar entregas.

La documentación de esta carpeta describe requisitos académicos externos al proyecto y no debe modificarse para adaptarla a decisiones de implementación.

Si existe una contradicción entre una decisión técnica del proyecto y un requisito documentado aquí, la contradicción debe señalarse explícitamente antes de modificar el requisito.
